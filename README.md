# 🛡️ DESTROYER445 - Phish Awareness Scanner

> Don't get phished machaa! Learn to detect fake links like a pro.

A simple, powerful **educational tool** built in Python for Termux to detect phishing URLs.

### ✨ Features
- ✅ HTTPS checker
- 🚨 IP-based URL detection
- 🔍 Suspicious characters (@, long URL) finder
- 🔤 Fake domain spelling detection (g00gle, faceboook etc)
- 📊 Risk Score System (0-10)

### 🚀 How to Use (Termux)
```bash
pkg install python
git clone https://github.com/DESTROYER445/Phish-Awareness-Scanner
cd Phish-Awareness-Scanner
python phish-check.py
